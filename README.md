# tg-lite

Лёгкий веб-клиент Telegram для обычного аккаунта. Только текст.

Работает целиком в браузере: протокол Telegram (MTProto) идёт через
[GramJS](https://github.com/gram-js/gramjs) по WebSocket напрямую к серверам
Telegram. Своего сервера и базы нет.

## Что умеет

- Вход по номеру телефона, коду и облачному паролю (2FA).
- Список чатов (последние 100) с поиском по названию и счётчиком непрочитанных.
- История чата с подгрузкой старых сообщений при прокрутке вверх.
- Отправка текста (Enter — отправить, Shift+Enter — новая строка).
- Новые сообщения в реальном времени, отметка прочитанного.
- Светлая и тёмная тема по системной, мобильная раскладка.

Медиа, стикеры и служебные сообщения показываются меткой `[медиа]` /
`[служебное сообщение]`. Правки и удаления в реальном времени не отображаются.

## Ключи

Нужны свои `api_id` и `api_hash`: <https://my.telegram.org/apps> →
API development tools. Они вводятся на первом экране и хранятся только в
`localStorage` этого браузера, вместе с сессией. В репозиторий ничего не попадает.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статические файлы в dist/
```

`dist/` — обычная статика, раздаётся любым веб-сервером (nginx, Caddy,
GitHub Pages).

## Безопасность

Сессия в `localStorage` — это полный доступ к аккаунту. Любой, кто получит
доступ к этому браузеру или сможет выполнить JS на том же домене, получит
аккаунт. Не размещайте клиент на одном домене с чужим кодом. «Выйти»
завершает сессию на серверах Telegram.
